Regras obrigatórias

Este é um projeto Android baseado em Gradle.

A estrutura do projeto é considerada crítica e não deve ser alterada, exceto se eu solicitar explicitamente.

Estrutura

- Considere a pasta atual como a raiz do projeto.
- Nunca crie uma nova pasta contendo o projeto inteiro.
- Nunca mova arquivos ou diretórios existentes.
- Nunca renomeie arquivos ou diretórios.
- Nunca reorganize a estrutura do projeto.
- Nunca crie uma cópia do projeto em outro diretório.
- Nunca altere a localização dos módulos Gradle.

Arquivos

- Crie novos arquivos e subdiretórios sempre que for útil ou necessário para manter o código organizado, modular, limpo e escalável.
- Sempre coloque novos arquivos na localização correta seguindo a estrutura padrão do projeto Android.
- Evite duplicar lógicas existentes e nunca crie arquivos temporários ou lixo no repositório.
- crie sempre arquivos para novas funcoes e organize em pastas

Gradle

- Nunca modifique "settings.gradle", "settings.gradle.kts", "build.gradle", "build.gradle.kts", "gradle.properties", "local.properties" ou a pasta "gradle/", a menos que eu peça explicitamente.
- Nunca altere o nome do módulo "app".
- Nunca altere "applicationId", "namespace", "compileSdk", "targetSdk", "minSdk" ou versões de plugins sem autorização.

Segurança

Você tem permissão total para criar novos arquivos e subdiretórios necessários para cumprir as tarefas (como arquivos de layout XML, drawables ou código Kotlin/Java), desde que os coloque na localização correta seguindo a estrutura padrão de recursos e pacotes do projeto Android. Não é necessário pedir confirmação para criar novos arquivos e diretórios legítimos do projeto.

Antes de qualquer alteração que envolva remoção, movimentação de arquivos existentes ou renomeação de diretórios/arquivos originais do projeto, pare e peça confirmação.

Objetivo

Seu objetivo é modificar apenas os arquivos necessários para cumprir a tarefa solicitada, preservando completamente a estrutura do projeto Android.
